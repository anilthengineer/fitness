# Fitness

Kişisel antrenman, beslenme ve ilerleme takibi. Tek sayfa, internet bağlantısı olmadan da çalışır.

- Veriler yalnızca kullanılan tarayıcıda (localStorage) saklanır; sunucuya gönderilmez.
- Cihazlar arasında taşımak için uygulamadaki **Yedeği indir / Yedekten geri yükle** kullanılır.
- Telefonda: siteyi aç → tarayıcı menüsü → **Ana ekrana ekle**.
