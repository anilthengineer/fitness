# Fitness

Kişisel antrenman, beslenme ve ilerleme takibi. Tek sayfa, internet bağlantısı olmadan da çalışır.

- Veriler yalnızca kullanılan cihazın tarayıcısında (localStorage) saklanır; sunucuya gönderilmez.
- Cihazlar arasında taşımak için uygulamadaki **Yedeği indir / Yedekten geri yükle** kullanılır.
- Telefonda: siteyi aç → tarayıcı menüsü → **Ana ekrana ekle**.
- İnternette yiyecek arama: [Open Food Facts](https://world.openfoodfacts.org) (ODbL). Yalnızca aranan kelime veya barkod gönderilir.
- Asistan: kullanıcının kendi Google Gemini API anahtarıyla çalışır; anahtar yalnızca o cihazda saklanır ve yedeğe dahil edilmez.
